# Golf Tournament Lottery App: CI/CD Automation

A golf tournament lottery application with an automated **CI/CD pipeline built on GitHub Actions**. The pipeline runs the backend tests and deployment steps automatically, cutting the deployment/test cycle from **15 minutes to under 2 minutes**.

## Highlights

- Automated backend CI/CD pipeline with GitHub Actions
- Deployment/test cycle reduced from 15 minutes to under 2 minutes (over 85% faster)
- Manual, repetitive steps replaced by an automated workflow

## Tech Stack

- **Automation:** GitHub Actions, CI/CD
- **Version control:** Git, GitHub
- **Front end:** HTML

## CI/CD Workflow

The pipeline is defined in the `.github/workflows` folder and runs the backend tests and deployment steps automatically.
